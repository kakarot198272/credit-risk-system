# Historical exploratory scripts

These original scripts are retained to support learning and comparison with version 2. They are not supported training commands.

Known issues include selecting models with self-estimated profit, relying on absent prediction CSVs, accuracy labels reversed relative to the default target, and creating forced-default copies before splitting data. The synthetic relabeling experiment is not evidence of real credit performance.

Use `python -m src.models.train` and the interactive validation-policy explorer for the supported pipeline. Git history preserves the earlier implementation in full.
